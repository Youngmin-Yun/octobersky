자주 묻는 질문 Frequently Asked Questions

알람이 울리지 않아요 My alarm isn't ringing

설정 → 알림 → Dayager 에서 알람 권한이 켜져 있는지 확인해 주세요. 무음 모드나 저전력 모드에서도 알람은 울리지만, 기기 설정에서 알람 권한 자체가 꺼져 있으면 울리지 않을 수 있습니다.

Check that alarm permission is enabled in Settings → Notifications → Dayager. Alarms still ring in Silent Mode or Low Power Mode, but they won't ring at all if the alarm permission itself is turned off.

언어를 바꿨는데 브리핑이 그대로예요 I changed the language, but the briefing didn't change

설정 → 언어 설정에서 원하는 언어를 선택하면 화면과 음성 브리핑 모두 즉시 반영됩니다. 기기의 시스템 언어와는 별개로 작동하니, 두 설정이 다르게 되어 있어도 정상입니다.

Selecting a language in Settings → Language applies immediately to both the on-screen text and the spoken briefing. This is independent of your device's system language, so it's fine if the two are set differently.

날씨나 현재 위치가 안 나와요 Weather or my location isn't showing up

설정 → 개인정보 보호 및 보안 → 위치 서비스 → Dayager 에서 위치 권한이 허용되어 있는지 확인해 주세요.

Check that location access is allowed in Settings → Privacy & Security → Location Services → Dayager.

캘린더 일정이 브리핑에 안 나와요 My calendar events aren't included in the briefing

설정 → 개인정보 보호 및 보안 → 캘린더 → Dayager 에서 캘린더 접근이 허용되어 있는지 확인해 주세요.

Check that calendar access is allowed in Settings → Privacy & Security → Calendars → Dayager.
